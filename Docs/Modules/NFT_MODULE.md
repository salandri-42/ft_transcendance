## Custom Major Module: NFT Generation & Blockchain Integration

### Why we chose this module

We chose to implement this module to explore a completely new and challenging domain: blockchain technology and NFTs.  
As software engineering students, we wanted to step outside our comfort zone and experiment with decentralized systems, which are becoming increasingly important in modern applications.

This module allowed us to go beyond traditional backend development and interact with real-world blockchain infrastructure, even if deployed in a test environment.

---

### Technical Challenges

The main technical challenges we faced were:

- Understanding how blockchain works, including concepts such as decentralization, immutability, and transactions.
- Learning how NFTs function, especially metadata handling and token standards.
- Managing the full pipeline required to mint an NFT:
  - Generating the artwork dynamically
  - Uploading assets to IPFS via Pinata
  - Interacting with a smart contract deployed on a test blockchain to mint the NFT
- Designing a microservices architecture using NestJS and Docker to orchestrate all these steps efficiently.
- Handling asynchronous processes and ensuring reliability between services.

This module required combining multiple technologies and ensuring smooth communication between them.

---

### Value Added to the Project

This module significantly enhances the project by introducing:

- A real-world use case of blockchain integration in a controlled test environment
- Permanent storage of generated artworks using IPFS (via Pinata)
- NFT minting on a test blockchain, making each generated artwork unique and verifiable
- A scalable and modular backend using microservices

The generated artworks are stored permanently through decentralized technologies, making them:
- Immutable (cannot be altered)
- Verifiable (ownership can be proven)
- Decentralized (not controlled by a single entity)

Even though the system is deployed on a test blockchain, it faithfully reproduces real-world conditions and workflows.

This adds strong technical and conceptual value to the project.

---

### Why this deserves Major Module status

This module is not a trivial feature. It involves:

- Integration with external decentralized infrastructure (IPFS & blockchain)
- Smart contract interaction on a blockchain network
- Complex orchestration across multiple services
- Advanced concepts beyond standard web development

It required significant research, experimentation, and problem-solving.

For these reasons, we believe this module fully meets the expectations of a Major module, demonstrating both technical depth and innovation.
