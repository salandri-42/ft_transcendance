# User Management

## Accessing the User Dashboard
- While connected, click the avatar to open the user dashboard.
- From the dashboard, you can access the artwork creation calendar.
- You can also add friends using code sharing.

## Accessing User Information and Profile Edit
- Click the username to open the user information page.
- From this page, you can edit your profile:
  - Upload or change avatar
  - Change username
  - Change password
