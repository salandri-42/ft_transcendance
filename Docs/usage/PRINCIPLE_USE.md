# Principle Use of the Project

## User Flow
1. Create an account using one of two options:
   - Email
   - 42 OAuth
2. Complete registration and verify the email.
3. Validate 2FA security.
4. Enter the 3D experience:
   - Click an already created star, or
   - Click the 3D globe to start a conversation and create an artwork.
5. Optional shortcut:
   - Double-click directly on the globe to skip conversation and create an artwork immediately.

## Summary
The main usage path is: **authenticate securely → access the 3D universe → interact and create artworks**.
