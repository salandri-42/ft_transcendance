# Project Roles and Responsibilities

This document describes the team roles used during the development of **ft_transcendence**.

## Role Assignment
- **Product Owner (PO):** arakoton
- **Project Manager (PM) / Scrum Master:** salandri
- **Technical Lead / Architect:** nandrian
- **Developers:** all team members

## Product Owner (PO) — arakoton
The PO defines product direction and ensures the project answers user needs.

Responsibilities:
- Defines the product vision.
- Maintains the product backlog.
- Prioritizes features.
- Makes final decisions on features and priorities.
- Validates completed work.
- Communicates with stakeholders (evaluators, peers).

## Project Manager (PM) / Scrum Master — salandri
The PM/Scrum Master ensures smooth team execution and coordination.

Responsibilities:
- Organizes team meetings and planning sessions.
- Tracks progress and deadlines.
- Ensures team communication.
- Manages risks and blockers.
- Facilitates collaboration and removes obstacles.

## Technical Lead / Architect — nandrian
The Tech Lead oversees technical direction and engineering consistency.

Responsibilities:
- Defines technical architecture.
- Makes technology stack decisions.
- Ensures code quality and best practices.
- Reviews critical code changes.

## Developers — all team members
All contributors also act as developers.

Responsibilities:
- Write code for assigned features.
- Participate in code reviews.
- Test their implementations.
- Document their work.
